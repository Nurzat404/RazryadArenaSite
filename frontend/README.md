# РазрядАрена Frontend

Клиентская часть РазрядАрены на Nuxt 3, Vue 3, TypeScript, Bootstrap 5 и Pinia.

## Запуск

```bash
npm install
npm run dev
```

Сайт откроется на `http://127.0.0.1:3000`. Для доступа из локальной сети используйте `npm run dev:host`.

## Проверка

```bash
npm run typecheck
npm run build
```

## Текущее состояние

Завершается этап 9.1: профиль, главная после входа, команды, рейтинги, турниры и матчи работают на мок-сервисах. Изменения пользователей и команд сохраняются в cookies браузера, поэтому не пропадают после обновления страницы. Это временное хранилище до подключения Express и MongoDB.

Следующий этап по `DEVELOPMENT_PLAN.md` - пользовательские сценарии турниров.
