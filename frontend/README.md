# РазрядАрена Frontend

Клиентская часть РазрядАрены на Nuxt 3, Vue 3, TypeScript, Bootstrap 5 и Pinia.

## Запуск

```bash
npm install
npm run dev
```

Сайт откроется на `http://127.0.0.1:3000`. Для доступа из локальной сети используйте `npm run dev:host`.

## Проверка

```bash
npm run typecheck
npm test
npm run build
```

## Текущее состояние

Завершён этап 14. На изменяемых мок-данных работают профиль, команды, персональные приглашения, заявки на турниры, карточки заявок, турнирные составы, сетка, расписание, матчи и ввод результатов. После сохранения интерфейс сразу показывает новое состояние; результат можно безопасно изменить, а карточка матча хранит полный протокол и историю правок. Для CS2 добавлен Map Veto: стандартные и пользовательские карты, форматы по стадиям, запуск по времени матча, ban/pick, таймаут и административные действия.

Мок-данные сохраняются в `localStorage`; cookie используется только для тестовой сессии пользователя. Реальных паролей, писем, общей базы между устройствами и серверных прав доступа пока нет.
