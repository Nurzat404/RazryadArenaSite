# Дизайн-система frontend

Компоненты этапа 3 дают общий UI-слой для страниц РазрядАрены.

## Базовые компоненты

- `BaseButton`
- `BaseInput`
- `BaseSelect`
- `BaseTextarea`
- `BaseModal`
- `BaseTabs`
- `BaseBadge`
- `BaseTable`
- `BasePagination`
- `BaseEmptyState`
- `BaseLoader`
- `BaseToast`

## Доменные компоненты

- `SportBadge`
- `StatusBadge`
- `UserAvatar`
- `TeamAvatar`
- `RatingBadge`
- `MatchScore`
- `DateTimeView`

## Поддерживаемые статусы

- `registration_open`
- `registration_closed`
- `active`
- `finished`
- `pending`
- `approved`
- `rejected`
- `excluded`
- `team_excluded`
- `scheduled`
- `technical_win`

Дальше страницы можно постепенно переводить с локальной разметки на эти компоненты.
